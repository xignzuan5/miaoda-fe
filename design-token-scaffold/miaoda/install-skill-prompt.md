# 妙搭固定技能安装指令

妙搭的“告诉妙搭创建技能”入口是对话式安装器。使用下面的固定指令时，Agent 只能读取并注册项目中已经写好的定义，不得自行设计、补写、删改或改名。

## 安装 `/页面开发`

```text
请把当前项目中已经写好的固定技能注册为项目技能，不要重新设计或改写技能内容。

唯一来源文件：design-system/miaoda/extensions/slash-page-development.md
技能名称必须是：页面开发
技能命令必须是：/页面开发

执行要求：
1. 先读取上述文件；如果文件不存在、无法读取或内容不完整，立即停止并报告，不要根据自己的理解补写。
2. 将文件中的 frontmatter、描述、执行规则、验证规则和示例原样作为技能定义来源。
3. 不得增加、删除、改写、翻译、摘要或重排任何规则；不得把“页面开发”改成其他名称。
4. 创建后回显实际注册的技能名称、命令和来源文件路径，并说明是否完整采用了来源文件。
5. 后续执行该技能时，每次都必须重新读取来源文件和 design-system/docs/miaoda-agent.md；来源文件是唯一规则源。
```

## 安装 `@设计变量解析`

如果当前妙搭租户支持创建自定义 `@` 插件，使用同样的方式注册：

```text
请把当前项目中已经写好的固定插件定义注册为 @ 插件，不要重新设计或改写插件内容。

唯一来源文件：design-system/miaoda/extensions/at-design-variable-parser.md
插件名称必须是：设计变量解析
插件触发方式必须是：@设计变量解析

先读取来源文件；文件不存在或无法完整读取就停止。必须原样采用文件中的规则、产物和完成检查，不得自行补写或删改。创建后回显实际注册名称、触发方式和来源文件路径。
```

如果当前租户没有自定义 `@` 插件入口，不要把它偷偷改成另一个技能。此时固定回退方式是使用官方 `@文件解析`，附加 `at-design-variable-parser.md` 和审计文件，并要求 Agent 严格按附件原文执行。
